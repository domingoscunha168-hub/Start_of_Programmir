# Information

Repositório de estudos com exercícios, anotações e pequenos projetos de programação. O foco está em lógica de programação, orientação a objetos, automação, manipulação de dados e prática com Python, com alguns apontamentos em JavaScript.

## Resumo

Este diretório reúne scripts criados para estudo e experimentação. A maior parte dos ficheiros são exercícios independentes, por isso o conteúdo inclui testes simples, desafios de lógica, rotinas utilitárias e versões de aprendizagem.

## Conteúdo

- Exercícios de lógica e algoritmos
- Rotinas de entrada e saída de dados
- Manipulação de texto, listas e números
- Estudos com estruturas de repetição e condicionais
- Scripts de apoio para cálculos e conversões
- Anotações e ficheiros experimentais
